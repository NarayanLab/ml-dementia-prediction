# Machine Learning for Dementia Risk Prediction

Clinical decision support tools for predicting 5-year dementia risk in patients with atrial fibrillation. 

## Try the reviewer demo

[Open the live demo portal](https://ml-dementia-prediction-1.onrender.com/).

Use the on-screen form with example values to generate an estimated five-year dementia risk. The hosted demo runs in your browser and requires no local installation.

For local setup and verification, see the [Clinical App README](Clinical%20App/README.md).

## Contents

- `Clinical App/` - Web application (React + FastAPI) with XGBoost-Cox model
- `af-dementia-survival/` - Python package for survival model development and validation
